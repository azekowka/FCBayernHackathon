## If something goes wrong

- **Phones out of sync** → press _Reset demo_ on the laptop; both phones update over SSE (or polling).
- **No network** → `AI_MODE=demo pnpm start` — badges show “Demo AI”, the flow is identical.
- **Questions on numbers** → “All figures are model outputs on synthetic data, calibrated to the published 135k–350k requests and 75,024 seats; the pilot measures the real rates.”

## Likely jury questions

- _Isn’t this dynamic pricing?_ — No. Prices never change; only who uses an empty seat does.
- _Privacy?_ — Opt-in signals only, the estimate is designed to run on the phone, the club learns nothing unless the fan taps release. No biometrics.
- _Why trust an AI with tickets?_ — It never decides. Allocation is a deterministic, published, verifiable algorithm; Gemini only talks.
- _Why Gemini?_ — Multilingual, structured output for intents, and the Google partnership; the model is swappable behind one interface.
